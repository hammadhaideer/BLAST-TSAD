# BLAST-TSAD

Code for BLAST: Bounded-Latency Attribution for Streaming Time-Series Anomaly Detection.

BLAST separates anomaly-score attribution time from the time at which causal evidence becomes available under a bounded latency budget.

## Repository status

This initial public release contains only core implementation and protocol configuration files.

The following are intentionally excluded during manuscript preparation:

- manuscript source and submitted PDF
- figures
- experimental results and tables
- pointwise scores and intermediate artifacts
- datasets
- model checkpoints
- internal audit and development records

Additional reproducibility material may be released later.

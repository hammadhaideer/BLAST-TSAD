# Paper figure assets

This directory contains the final BLAST figures used as public documentation for the ICASSP 2027 submission.

- `Figure1.png` — endpoint assignment versus BLAST attribution.
- `Figure2_BLAST_final.png` — causal score generation, BLAST attribution, and the frozen U237→M70 protocol.
- `Figure3_M70_family_gain_FINAL.pdf` — original vector family-wise M70 confirmation figure.
- `Figure3_M70_family_gain_FINAL.png` — PNG rendering of Figure 3 for GitHub/Markdown display.

The figures are documentation assets only. No experiment script reads them, and they do not affect numerical reproduction.

Integrity hashes are recorded in `SHA256SUMS.txt` and checked by `scripts/verify_repository.py`.
